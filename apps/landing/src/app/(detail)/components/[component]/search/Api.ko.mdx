###### API

`Search` props는 `Input` props(`type` 제외)를 확장하므로 `value`, `defaultValue`, `onChange`, `error`, `errorMessage`, `classNames`, `colors`가 [Textbox](/components/textbox)에서와 같이 동작합니다. `<input type="search">`를 렌더링하므로 보조 기술은 이를 검색 상자로 안내합니다.
