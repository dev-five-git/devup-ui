###### API

`Search` props extend the `Input` props (except `type`), so `value`, `defaultValue`, `onChange`, `error`, `errorMessage`, `classNames` and `colors` work as they do on [Textbox](/components/textbox). It renders an `<input type="search">`, which assistive technology announces as a search box.
