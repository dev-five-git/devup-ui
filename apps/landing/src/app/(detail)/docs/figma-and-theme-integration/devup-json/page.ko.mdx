# devup.json 설정

`devup.json` 파일은 Devup UI의 핵심 설정 파일로, 사용자 정의 테마, 색상, 타이포그래피 등 다양한 디자인 토큰을 정의할 수 있습니다.

## 기본 구조

```json
{
  "theme": {
    "colors": {
      "default": {
        "primary": "#5A44FF"
      }
    },
    "typography": {
      "h1": {
        "fontSize": "32px"
      }
    }
  }
}
```

## 색상 설정

`theme.colors`는 변형 이름(`default`, `light`, `dark` 또는 직접 정한 이름)을
토큰 맵에 대응시킵니다. 평면적인 `colors.primary` 값은 테마 스키마에 맞지 않으므로,
`colors.default.primary`처럼 변형 아래에 배치해야 합니다.

### **기본 색상 설정**

테마별로 색상을 정의합니다.

```json
{
  "theme": {
    "colors": {
      "light": {
        "primary": "#5A44FF",
        "secondary": "#85A5F2",
        "text": "#2F2F2F",
        "background": "#FFF"
      },
      "dark": {
        "primary": "#9086FF",
        "secondary": "#2A4586",
        "text": "#EDEDED",
        "background": "#131313"
      }
    }
  }
}
```

### **의미 기반 색상 이름**

용도를 설명하는 의미 기반 이름을 사용합니다.

```json
{
  "theme": {
    "colors": {
      "light": {
        "primary": "#5A44FF",
        "primaryHover": "#4D38AE",
        "text": "#2F2F2F",
        "textSecondary": "#787878",
        "background": "#FFF",
        "surface": "#F8F8F8",
        "success": "#4CAF50",
        "warning": "#FF9800",
        "error": "#F44336"
      }
    }
  }
}
```

### **색상 변형**

불투명도를 적용한 색상 변형을 만듭니다.

```json
{
  "theme": {
    "colors": {
      "light": {
        "primary": "#5A44FF",
        "primary50": "#5A44FF80",
        "primary20": "#5A44FF33",
        "black50": "#00000080"
      }
    }
  }
}
```

## 타이포그래피 설정

### **타이포그래피 속성**

각 타이포그래피 정의에는 다음 속성을 포함할 수 있습니다.

- **fontFamily**: 글꼴 패밀리 이름
- **fontWeight**: 숫자 굵기(100-900) 또는 문자열
- **fontSize**: 단위를 포함한 크기(`16px`, `1rem`)
- **lineHeight**: 숫자 비율 또는 단위를 포함한 문자열
- **letterSpacing**: 단위를 포함한 자간(`-0.03em`)

### **타이포그래피 구성**

정적인 값은 객체로, 반응형 브레이크포인트는 배열로 타이포그래피 스타일을 정의합니다.

#### **정적 타이포그래피**

```json
{
  "theme": {
    "typography": {
      "caption": {
        "fontFamily": "Pretendard",
        "fontWeight": 500,
        "fontSize": "14px",
        "lineHeight": 1.4
      }
    }
  }
}
```

#### **반응형 타이포그래피**

배열을 사용해 브레이크포인트마다 스타일을 정의합니다.

```json
{
  "theme": {
    "typography": {
      "heading": [
        {
          "fontFamily": "Pretendard",
          "fontWeight": 700,
          "fontSize": "20px",
          "lineHeight": 1.3
        },
        {
          "fontFamily": "Pretendard",
          "fontWeight": 700,
          "fontSize": "28px",
          "lineHeight": 1.3
        },
        {
          "fontFamily": "Pretendard",
          "fontWeight": 700,
          "fontSize": "32px",
          "lineHeight": 1.2
        }
      ]
    }
  }
}
```

## 컴포넌트에서 사용

### **색상 사용**

`$` 접두사로 색상에 접근합니다.

```tsx
<Box bg="$primary" color="$text">
  Content
</Box>
```

선택한 변형에 정의된 토큰만 사용하세요. 기본 구조 예시는
`$primary`만 정의하므로, `$text`를 사용하려면 먼저 해당 변형에 `text`를 추가해야 합니다.

### 생성된 테마 타입

빌드 플러그인은 `distDir` 안에 `theme.d.ts`를 생성합니다. 기본
`distDir`은 `df`이므로 기본 선언 파일 경로는 `df/theme.d.ts`입니다. 타입
자동 완성을 활성화하려면 생성된 선언 파일을 `tsconfig.json`에 포함합니다.

```json
{
  "include": ["src", "df/*.d.ts"]
}
```

`distDir`은 빌드 플러그인 옵션이며 `devup.json`의 필드가 아닙니다. 예를 들어
Vite 설정에서 생성 디렉터리를 변경할 수 있습니다.

```ts
import DevupUI from '@devup-ui/vite-plugin'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [DevupUI({ distDir: 'generated/devup' })],
})
```

이 설정은 `generated/devup/theme.d.ts`를 생성하므로, `df/*.d.ts` 대신
`generated/devup/*.d.ts`를 포함해야 합니다. 테마를 변경한 후에는 빌드 플러그인을
실행해 선언 파일을 다시 생성하세요.

### **타이포그래피 사용**

`typography` prop으로 타이포그래피 스타일을 적용합니다.

```tsx
<>
  <Text typography="h1">Heading 1</Text>
</>
```
