# N/M 진법

Devup UI는 자체 N/M 진법을 사용해 CSS 제약과 광고 차단기 호환성에 맞게 최적화된, 짧고 충돌 없는 클래스 이름을 생성합니다.

- **짧은 클래스 이름 생성**: `a`, `b`, `c`처럼 짧고 효율적인 클래스 이름을 만듭니다
- **CSS 제약 회피**: 클래스 이름이 숫자로 시작하지 않습니다
- **광고 차단기 충돌 방지**: 콘텐츠 차단기에 걸리는 패턴을 피합니다
- **고유성 보장**: 각 스타일은 고유하고 결정적인 클래스 이름을 받습니다
- **크기 최적화**: 효율을 극대화하도록 클래스 이름 길이를 최소화합니다

## 동작 원리

### **진법 체계**

N/M 진법은 두 가지 문자 집합을 사용합니다.

- **N 진법**: `a-z, _` (27자)
- **M 진법**: `a-z, 0-9, _` (37자)

### **숫자 변환**

숫자는 두 단계 방식으로 N/M 진법으로 변환됩니다.

1. **0 처리**: 숫자가 0이면 `a`를 반환합니다
2. **진법 변환**: 첫 번째 문자는 N 진법에서 가져오므로 이름이 숫자로
   시작하지 않으며, 그 뒤의 모든 문자는 M 진법에서 가져옵니다
   - N 진법 순서: `abcdefghijklmnopqrstuvwxyz_` (27자)
   - M 진법 순서: `abcdefghijklmnopqrstuvwxyz0123456789_` (37자)
   - 0부터 26까지는 한 글자 이름 27개 `a` … `z`, `_`이고, 27은
     `aa`, 28은 `ab`와 같은 식으로 이어집니다
3. **광고 차단기 충돌 방지**: 결과가 "ad"로 끝나면 "a-d"로 바꿉니다
   (숫자 30은 `ad`가 아니라 `a-d`입니다)

### **클래스 이름 생성**

클래스 이름은 다음 단계를 거쳐 생성됩니다.

1. **스타일 시그니처 생성**: 속성, 레벨, 값, 선택자, 스타일 순서를 조합해 고유한 키를 만듭니다
2. **파일 식별자 추가**: 파일별 CSS 분할을 위해 파일 이름을 숫자로 변환합니다
3. **순차 번호 할당**: GLOBAL_CLASS_MAP에서 고유 스타일이 등장한 순서에 따라 순차 번호를 할당합니다
4. **N/M 진법 변환**: N/M 진법을 사용해 순차 번호를 알파벳 클래스 이름으로 변환합니다
5. **최종 조합**: 파일 식별자가 있으면 파일 식별자와 클래스 번호를 조합해 최종 클래스 이름을 만듭니다

## 광고 차단기 호환성

### **"ad"가 문제가 되는 이유**

광고 차단기는 "ad" 패턴이 포함된 클래스 이름을 광고로 인식해 차단합니다.

- **광고 차단 필터**: "ad" 문자열이 포함된 요소를 광고로 분류합니다
- **CSS 차단**: 스타일이 적용되지 않아 UI가 깨집니다
- **나쁜 사용자 경험**: 의도치 않은 스타일 차단으로 레이아웃 문제가 생깁니다

### **해결 방법**

Devup UI는 다음 방법으로 광고 차단기와의 충돌을 방지합니다.

- **패턴 회피**: "ad"로 끝나는 클래스 이름을 자동으로 "a-d"로 바꿉니다
- **안전한 문자만 사용**: 차단 패턴을 피하도록 `a-z`, `0-9`, `_`, `-`만 사용합니다
- **숫자로 시작하지 않음**: 숫자는 첫 번째 문자 뒤에만 나타나므로 클래스 이름이 CSS 제약을 준수합니다

## 장점

- **짧은 클래스 이름**: 처음 27개 스타일은 `a`, `b`, `c` 같은 한 글자 이름을 받습니다
- **빌드 일관성**: 같은 입력에는 항상 같은 클래스 이름을 생성합니다
- **캐시 최적화**: 일관된 클래스 이름으로 브라우저 캐시 효율이 높아집니다
- **충돌 방지**: 각 스타일이 고유한 시그니처를 가지므로 클래스 이름이 충돌하지 않습니다
- **광고 차단기 호환성**: "ad" 패턴을 자동으로 "a-d"로 바꿔 차단을 방지합니다
- **CSS 제약 준수**: 클래스 이름이 숫자로 시작하지 않으므로 CSS 규칙을 준수합니다
