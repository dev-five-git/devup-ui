# CSS 최적화

Devup UI는 빌드 시점에 스타일을 추출하고, 지원하는 값을 정규화하며, 동일한
원자적 규칙을 재사용합니다. 범용 CSS 압축기는 아니므로, 모든 소수나 축약형이
줄어든다고 가정하지 마세요.

아래의 각 입력은 독립된 소스 파일입니다. 빌드 플러그인을 설정한 상태에서, 표시된
CSS는 빈 테마(`{}`)와 기본 접두사로 격리된 추출을 실행해 출력한 결과입니다.
생성되는 클래스, keyframe, 레이어 이름은 추출 상태와 접두사에 따라 달라지므로
직접 참조할 수 있는 안정적인 식별자가 아닙니다.

## 값과 단위 최적화

```tsx
import { Box } from '@devup-ui/react'

const values = <Box m="0px 0px 0px 0px" p="16.0000px" w="0px" />
const ratios = (
  <>
    <Box aspectRatio="500/100" />
    <Box aspectRatio="16/9" />
  </>
)
const units = (
  <>
    <Box w={16} />
    <Box w="16rem" />
    <Box w="100%" />
  </>
)
```

생성된 CSS:

```text
/*! devup-ui v1.0.82 | Apache License 2.0 | https://devup-ui.com */.e{aspect-ratio:16/9}.d{aspect-ratio:5/1}.a{margin:0 0 0 0}.b{padding:16.0000px}.c{width:0}.h{width:100%}.g{width:16rem}.f{width:64px}
```

- 이 예시에서 0 길이는 단위가 제거되지만, 네 개의 margin 값은
  `0 0 0 0`으로 남으며 하나의 값으로 합쳐지지 않습니다.
- 명시적인 소수 문자열 `16.0000px`는 `16px`로 줄어들지 않고 그대로 유지됩니다.
- 정수 종횡비 `500/100`은 `5/1`로 약분되며, `16/9`는 바뀌지 않습니다.
- 숫자 width는 Devup UI의 스케일을 사용하므로 `16`은 `64px`가 됩니다. 명시적인 `rem`과
  퍼센트 단위는 그대로 유지됩니다. `opacity`나 `aspectRatio` 같은
  단위 없는 속성에는 이 4배 스케일이 적용되지 않습니다.

## 색상 최적화

다음 RGB, RGBA, hex 입력은 색상 정규화, hex 축약, 완전 불투명 알파 제거를
보여 줍니다. 이 관찰 결과가 모든 CSS 색상 문법의 변환을 보장하지는 않습니다.

```tsx
import { Box } from '@devup-ui/react'

const colors = (
  <>
    <Box bg="rgb(255, 0, 0)" />
    <Box bg="rgba(255, 0, 0, 0.5)" />
    <Box bg="#ffffff" />
    <Box bg="#000000" />
    <Box bg="#ff0000" />
    <Box bg="#ffffffff" />
    <Box bg="#000000ff" />
    <Box bg="#ff0000ff" />
    <Box bg="#ff000080" />
  </>
)
```

생성된 CSS:

```text
/*! devup-ui v1.0.82 | Apache License 2.0 | https://devup-ui.com */.d{background:#000}.a{background:#F00}.b{background:#FF000080}.c{background:#FFF}
```

RGB 빨강, 6자리 빨강, 완전 불투명한 8자리 빨강은 모두 `#F00`을 공유합니다. 흰색과
검은색도 마찬가지로 불투명 알파 형식을 포함해 `#FFF`와 `#000`으로 축약됩니다.
알파가 `0.5`인 RGBA 입력은 `#FF000080`을 출력하며, 이 예제의 동등한 hex
입력도 같습니다. 알파 바이트 `80`은 같은 hex 숫자 하나를 반복한 형태로
축약할 수 없습니다. 특히 `#f000`은 반투명 빨강이 아니라 완전히 투명한
빨강을 의미합니다.

## 전역 CSS 추출

전역 규칙을 추출하려면 `globalCss()`를 사용합니다. 이 예시는 생성된 캐스케이드 레이어
안에 간결한 규칙을 출력합니다. 임의의 CSS 텍스트 블록을 압축하는 것을
보여 주는 예시는 아닙니다.

```tsx
import { globalCss } from '@devup-ui/react'

globalCss({ div: { backgroundColor: 'red' } })
```

생성된 CSS:

```text
/*! devup-ui v1.0.82 | Apache License 2.0 | https://devup-ui.com */@layer b;@layer b{div{background-color:red}}
```

## Keyframes 추출

`keyframes()`는 생성된 애니메이션 이름을 반환합니다. 이 이름은
JavaScript 변수 이름 `fadeIn`에서 파생되지 않습니다.

```tsx
import { Box, keyframes } from '@devup-ui/react'

const fadeIn = keyframes({
  from: { opacity: 0 },
  to: { opacity: 1 },
})
const animated = <Box animation={`${fadeIn} 1s linear`} />
```

생성된 CSS:

```text
/*! devup-ui v1.0.82 | Apache License 2.0 | https://devup-ui.com */@keyframes a{from{opacity:0}to{opacity:1}}.b{animation:a 1s linear}
```

## 글꼴 패밀리 추출

`fontFamily`를 설정하면 font-family 선언이 출력됩니다. 글꼴 파일을 찾거나
`@font-face` 규칙을 자동으로 만들지는 않습니다. 글꼴은 별도로 불러오세요.

```tsx
import { Box } from '@devup-ui/react'

const text = <Box fontFamily="Inter" />
```

생성된 CSS:

```text
/*! devup-ui v1.0.82 | Apache License 2.0 | https://devup-ui.com */.a{font-family:Inter}
```

## 스타일 중복 제거

반복되는 동일한 선언은 원자적 클래스를 재사용합니다. 배경색과 글자색은
하나로 합쳐진 `.red-white` 규칙이 아니라 별도의 규칙으로 남습니다.

```tsx
import { Box } from '@devup-ui/react'

const repeated = (
  <div>
    <Box bg="red" color="white" />
    <Box bg="red" color="white" />
    <Box bg="red" color="white" />
  </div>
)
```

추출된 코드:

```text
import "@devup-ui/react/devup-ui.css";
const repeated = <div>
  <div className="a b" />
  <div className="a b" />
  <div className="a b" />
</div>;
```

생성된 CSS:

```text
/*! devup-ui v1.0.82 | Apache License 2.0 | https://devup-ui.com */.a{background:red}.b{color:white}
```

이 세 요소는 두 규칙을 공유합니다. 재사용은 런타임 스타일링용 JavaScript를
추가하지 않고도 반복되는 CSS를 줄여 줍니다. 위 예시는 관찰된 출력을 설명할 뿐,
모든 값에 대해 가능한 가장 짧은 표현을 보장하지는 않습니다.
