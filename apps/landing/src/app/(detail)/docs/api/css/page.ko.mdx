# css

`css` 함수는 문자열을 반환하는 함수입니다.

## 사용 방법

### CSS 리터럴

`css`를 태그 함수로 사용해 CSS 문자열을 만들 수 있습니다. CSS 속성 문자열을 인자로 전달하면
클래스 목록으로 변환됩니다.

{/* conformance */}

```tsx
import { css } from '@devup-ui/react'

function App() {
  return (
    <div
      className={css`
        background: red;
        width: 100px;
        height: 100px;
      `}
    />
  )
}
```

위 내용은 아래와 같이 렌더링/변환됩니다.

```tsx
function App() {
  return <div className="a b c" />
}
```

```css
.a {
  width: 100px;
}
.b {
  height: 100px;
}
.c {
  background: red;
}
```

### CSS 객체

CSS 객체를 인자로 전달하여 css 함수를 사용할 수도 있습니다.

{/* conformance */}

```tsx
import { css } from '@devup-ui/react'

function App() {
  return (
    <div
      className={css({
        background: 'red',
        width: '100px',
        height: '100px',
      })}
    />
  )
}
```

위 내용은 아래와 같이 렌더링/변환됩니다.

```tsx
function App() {
  return <div className="a b c" />
}
```

```css
.a {
  background: red;
}
.b {
  width: 100px;
}
.c {
  height: 100px;
}
```
