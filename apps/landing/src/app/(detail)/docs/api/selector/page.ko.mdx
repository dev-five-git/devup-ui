다른 의사 클래스나 의사 요소도 같은 방식으로 동작합니다. 예를 들어 `_nthChild`는 `:nth-child`, `_placeholder`는 `::placeholder`에 해당합니다. `_notASelector`처럼 아무것도 선택하지 않는 이름은 아무것과도 일치하지 않는 CSS를 만드는 대신 빌드 오류가 됩니다.

인자를 받는 의사 클래스는 `params`로 인자를 전달하며, 그룹 형태에서도 마찬가지입니다.

```tsx
const example = (
  <Box
    _groupNthChild={{ params: ['odd'], color: 'red' }}
    _nthChild={{ params: ['2n'], bg: 'gray' }}
  />
)
// :is([role=group],[data-group]):nth-child(odd) .a{color:red}
// .b:nth-child(2n){background:gray}
```

선택자는 스타일을 받습니다. 객체 또는 `_hover="color: red"` 같은 CSS 텍스트를 사용할 수 있습니다. 클래스 이름처럼 그 밖의 문자열은 빌드 오류가 됩니다.

## `selectors`

`selectors`는 모든 선택자를 받습니다. `&`가 있는 키에서는 그 위치에 요소가 들어가고, `&`가 없는 키는 요소를 기준으로 해석됩니다.

- `hover`나 `focusVisible` 같은 의사 클래스 이름은 요소의 해당 의사 클래스가 됩니다. `div`처럼 아무것도 선택하지 않는 이름은 빌드 오류입니다
- `:`, `::`, `[`로 시작하는 키는 `':hover'`나 `'[aria-busy]'`처럼 요소 자체에 적용됩니다
- 그 밖의 선택자는 `'.child'`, `'> p'`, `'div p'`처럼 하위 요소를 선택합니다

```tsx
const example = (
  <Box
    selectors={{
      '&:hover, .parent &': { color: 'red' },
      '[aria-busy]': { opacity: 0.5 },
      '> p': { m: 0 },
    }}
  />
)
// .a:hover{color:red}
// .parent .b{color:red}
// .c[aria-busy]{opacity:.5}
// .d > p{margin:0}
```

`styled`와 `css` 템플릿의 중첩 규칙은 styled-components 및 Emotion과 같이 동작합니다. `.child { }`와 `> p { }`는 하위 요소를 선택하고, `:hover { }`와 `::before { }`는 컴포넌트 자체에 적용되며, 선택자 목록 안에 중첩된 규칙은 목록의 각 선택자 아래에 적용됩니다.

## 스타일 객체의 중첩 선택자

스타일 객체도 Emotion 및 styled-components와 같이 동작합니다. `css()`, `globalCss()`, `styled.div({ ... })`, `styled(Component)({ ... })`, `css` prop, Emotion 및 styled-components import에서 값이 객체이고 어떤 스타일 속성도 가리키지 않는 키는 중첩 선택자입니다. `selectors` 키와 같은 방식으로 해석되지만, 의사 클래스를 선택하지 않는 이름은 빌드 오류 대신 하위 요소 선택자가 됩니다.

- `span` 같은 요소 이름이나 `'h1, h2'` 같은 선택자 목록은 하위 요소를 선택하며, 목록의 선택자마다 규칙이 하나씩 생성됩니다
- `hover`, `before`, `print` 같은 의사 클래스, 의사 요소, 미디어 축약형 이름은 `selectors`에서와 마찬가지로 해당 선택자가 됩니다
- `:`, `::`, `[`로 시작하는 키는 요소 자체에 적용되며, `&`는 요소가 들어갈 위치를 나타냅니다

```tsx
const title = css({
  color: 'red',
  span: { color: 'blue' },
  'h1, h2': { m: 0 },
  hover: { color: 'green' },
  '&.active': { fontWeight: 'bold' },
})
// .a{color:red}
// .b span{color:blue}
// .c h1{margin:0}
// .d h2{margin:0}
// .e:hover{color:green}
// .f.active{font-weight:bold}

globalCss({ body: { color: 'black', a: { color: 'blue' } } })
// body{color:black}
// body a{color:blue}
```

스타일 속성인 키는 값이 객체여도 원래 의미를 유지합니다. `p`는 Devup UI의 `padding` 축약형이므로 `p: { ... }`는 문단을 선택하지 않습니다. 문단을 선택하려면 `'& p'`를 작성합니다. 철자가 틀린 `colr: 'red'`처럼 문자열 값을 가진 키는 선언으로 유지됩니다. JSX props는 스타일 객체가 아닙니다. `<Box span={...} />`는 이전과 같이 `span`을 요소에 전달하므로, 여기에서 선택자를 중첩하려면 `selectors`나 `css` prop을 사용합니다.

## At-Rule

`_media`, `_supports`, `_container`는 쿼리를 키로, 스타일을 값으로 하는 레코드를 받습니다. Emotion처럼 쿼리를 키 자체에 작성할 수도 있으며, `globalCss`는 선택자 맵 전체를 감싸는 at-rule을 지원합니다.

```tsx
const example = (
  <Box
    _media={{ '(min-width: 500px)': { p: 2 } }}
    selectors={{ '@media print': { display: 'none' } }}
  />
)

globalCss({
  _motionReduce: { '*, *::before, *::after': { transition: 'none' } },
})
```

조건은 항상 브레이크포인트 값보다 우선합니다. at-rule 스타일은 모든 반응형 규칙 뒤에 옵니다. at-rule끼리는 조건에 따라 정렬되며, 너비 쿼리는 모바일 우선(`min-width` 오름차순, 그다음 `max-width` 내림차순)으로, 그 뒤에 미디어 타입, 기타 기능 쿼리 순이고, `prefers-*` 같은 사용자 환경 설정은 마지막에 옵니다.
