# Flex

The `Flex` component is a layout component that uses flexbox to layout its children.

It has a `display: flex` style by default.

## How to use

{/* conformance */}

```tsx
import { Flex } from '@devup-ui/react'

function App() {
  return <Flex />
}
```

The Flex component defined above will render like this:

```tsx
function App() {
  return <div className="a" />
}
```

```css
/* The component's own defaults sit in a lower cascade layer, so props override them */
@layer b {
  .a {
    display: flex;
  }
}
```
