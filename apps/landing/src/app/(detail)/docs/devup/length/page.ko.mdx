# Length

Devup UI는 간격, 크기, 모서리 반경(border-radius) 등 CSS 길이 속성에 사용할 수 있는 반응형 length 토큰을 지원합니다. 타이포그래피와 마찬가지로 length 토큰도 `devup.json`에서 반응형 배열로 정의할 수 있습니다.

## Length 토큰 정의

`devup.json`에 length 토큰을 정의합니다.

```json
{
  "theme": {
    "length": {
      "default": {
        "containerX": ["16px", null, "32px", null, "64px"],
        "gutter": ["8px", null, "16px"],
        "borderRadiusMd": ["8px", null, "16px"]
      }
    }
  }
}
```

배열의 각 인덱스는 하나의 브레이크포인트에 대응합니다. `null`을 사용하면 해당 브레이크포인트를 건너뛰고 이전 값을 그대로 이어받습니다.

## 사용법

길이 값을 받는 모든 prop에서 `$` 접두사를 붙여 length 토큰을 사용합니다.

```tsx
<>
  <Box px="$containerX" />
  <Box gap="$gutter" />
  <Box borderRadius="$borderRadiusMd" />
  <Box px="$containerX" />
</>
```

`"$token"`과 `{"$token"}` 모두 반응형 토큰을 브레이크포인트별 여러 클래스로 확장합니다.

{/* conformance: theme */}

```tsx
<Box gap="$gutter" />
```

`gutter`는 인덱스 0과 2에 정의되어 있으므로 prop은 각 인덱스마다 클래스를 하나씩 얻고, 두 클래스 모두 토큰의 CSS 변수를 읽습니다(테마는 브레이크포인트마다 `--gutter`를 정의합니다).

```css
.a {
  gap: var(--gutter);
}
@media (min-width: 768px) {
  .b {
    gap: var(--gutter);
  }
}
```

## 반응형 배열에서의 동작

`$token`이 반응형 배열 안에 있으면 확장되지 **않습니다**. 배열 자체가 브레이크포인트를 정의하기 때문입니다.

```tsx
{
  /* "$containerX" stays as a single class at breakpoint index 2 */
}
;<Box px={['8px', null, '$containerX']} />
```

인덱스 2의 클래스는 여전히 `var(--containerX)`를 읽습니다. 테마가 브레이크포인트와 테마 변형마다 `--containerX`를 다시 정의하므로, 해당 미디어 쿼리가 적용되는 곳에서는 언제나 토큰의 현재 값이 표시됩니다.

핵심적인 차이는 다음과 같습니다.

| 문법                                | 동작                                      | 클래스 수 |
| ----------------------------------- | ----------------------------------------- | --------- |
| `px="$containerX"`                  | 정의된 모든 브레이크포인트로 확장         | 여러 개   |
| `px={"$containerX"}`                | 정의된 모든 브레이크포인트로 확장         | 여러 개   |
| `px={["$containerX"]}`              | 인덱스 0에 `var(--containerX)`            | 1         |
| `px={["8px", null, "$containerX"]}` | 인덱스 0에 `8px`, 2에 `var(--containerX)` | 2         |

## 테마 변형

length 토큰은 색상과 마찬가지로 테마 변형을 지원합니다.

```json
{
  "theme": {
    "length": {
      "default": {
        "containerX": ["16px", null, "32px"]
      },
      "compact": {
        "containerX": ["8px", null, "16px"]
      }
    }
  }
}
```

## 반응형이 아닌 토큰

모든 브레이크포인트에서 하나의 값을 사용하려면 단순 문자열을 사용합니다.

```json
{
  "theme": {
    "length": {
      "default": {
        "borderRadiusSm": "4px",
        "borderRadiusMd": "8px",
        "borderRadiusLg": "16px"
      }
    }
  }
}
```

## 타입 안전성

length 토큰은 완전한 타입 안전성을 갖습니다. `$`를 입력하면 TypeScript가 사용 가능한 토큰을 자동 완성합니다.

```tsx
// 자동 완성 목록: $containerX, $gutter, $borderRadiusMd 등
<Box px="$" />
```
